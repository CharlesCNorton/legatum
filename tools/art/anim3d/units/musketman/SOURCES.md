# Musketman sources, round 1

- Painting: https://pub-fb5c281dd12d4ea4bbd38d657cdeb907.r2.dev/app/src/assets/units/musketman-source.png ; original project CC BY 4.0. Source registered by opaque bounds to the committed `musketman-256.png`. Both hashes are pinned in `assets.lock.json`; original and projection remain in external `assets/musketman/`.
- MPFB 2.0.18: https://github.com/makehumancommunity/mpfb2/releases/tag/v2.0.18 ; GPL software, CC0 anatomy, morphs and game_engine weights/rig output. Existing isolated install. MakeHuman system high-poly eyes: https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip ; CC0.
- Quaternius Universal Animation Library Standard, 2025-06-10: https://quaternius.com/packs/universalanimationlibrary.html ; CC0 1.0. Immutable mirror: https://raw.githubusercontent.com/J-Ponzo/gltf-universal-animation-library/e24c23cf2a1323488a3faa226ea7ea21f644b73e/glTF/AnimationLibrary_Godot_Standard.gltf and adjacent `.bin`. Existing external `assets/quaternius-ual/LICENSE`. Idle_Loop, Walk_Loop, Hit_Chest, Death01, and A_TPose reference. Exact source bytes checked against `motion.lock.json` before build and retarget.
- Hidden surface artwork: original project CC BY 4.0 mounted-family generated linen, coat, hair and bronze quadrants, 2026-11-22, `assets/horseman/fill-*.png`, original prompt retained in `reused-fills.prompt.txt`. No public generation URL. Buff, red and leather fills are recoloured locally by `prepare.py`. Frozen camera UVs on real meshes blend into these fills; there are no painting cards or live per-frame camera textures.
- Blender 5.3.0 https://www.blender.org/ (GPL software), Pillow 13.0.0 https://pypi.org/project/pillow/13.0.0/ (MIT-CMU), existing FFmpeg. All invocations through the PATH `blender` gate.
- Original musketman costume, hat, feather, musket, bayonet and attack keys: MIT scripts / CC BY 4.0 renders. Unit-local projection, bake and delivery helpers adapted from `astra/unit-anim-3d-barbarian-musketman` at `207d6ac4`; infantry standard read from `astra/unit-anim-3d-v2` at `d1d60f6f`. Standing geometry and locomotion mapping are specific to this unit.

Assets, bakes, editable blends and 512/256 masters stay under `~/LegatumRuns/anim-pilot/`. No paid service, account, Mixamo, model download or upload.
