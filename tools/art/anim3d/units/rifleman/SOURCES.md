# Rifleman round 1 sources

- Original Legatum rifleman painting: `app/src/assets/units/rifleman-256.png`, `rifleman-panel.png` and the adjacent base-edit prompt. Full source: https://pub-fb5c281dd12d4ea4bbd38d657cdeb907.r2.dev/app/src/assets/units/rifleman-source.png . CC BY 4.0, repository `LICENSE-ART`. Download retained only under external `assets/rifleman/painting-source.png`.
- MPFB 2.0.18: https://github.com/makehumancommunity/mpfb2/releases/tag/v2.0.18 . Add-on GPL-3.0-or-later; MakeHuman anatomy, morphs, rig weights and system eyes CC0. Reuses the isolated installation in `blender-user/`, 53-bone game_engine skeleton. No third-party software is vendored here.
- Quaternius Universal Animation Library Standard, 2025-06-10: https://quaternius.com/packs/universalanimationlibrary.html . CC0 1.0, local LICENSE retained. Idle_Loop, Walk_Loop, Hit_Chest, Death01. Immutable mirror: https://raw.githubusercontent.com/J-Ponzo/gltf-universal-animation-library/e24c23cf2a1323488a3faa226ea7ea21f644b73e/glTF/AnimationLibrary_Godot_Standard.gltf and adjacent `.bin`. Reference/rest matrices and bone rolls are compensated with Blender world-space COPY_ROTATION. A carrying-arm layer and a supporting-hand constraint preserve the two-handed rifle grip. No post-retarget foot orientation edit. Only the rifle aim/recoil is authored.
- Unseen-surface fills reuse original generated horseman linen and coat artwork, 2026-11-22, recolored to blue wool, faded trousers and leather. Full original prompt is retained in `reused-fills.prompt.txt`; external files are `assets/horseman/fill-linen.png` and `fill-coat.png`. These are generated material artwork, not downloaded photographs. Projection uses frozen rest-pose UVs on actual 3D meshes; no painting cards or per-frame reprojection.
- Original rifleman kit geometry and code adaptations: Legatum, 2026-11-23; code MIT, rendered art CC BY 4.0. Pipeline helpers adapted as a unit-local snapshot from the infantry worktree on `astra/unit-anim-3d-infantry`, with the family playbook consulted through `git show astra/unit-anim-3d-v2:tools/art/anim3d/PLAYBOOK.md`.

`assets.lock.json` pins exact painting, generated fill and motion input bytes. Generated masters and third-party assets stay outside git. No commercial motion libraries, accounts or paid services were used.
