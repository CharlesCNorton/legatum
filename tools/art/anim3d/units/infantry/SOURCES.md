# Infantry sources

All raw assets and editable masters stay in `~/LegatumRuns/anim-pilot/`.
`assets.lock.json` pins the exact painting, generated fills and motion inputs.

- **Painting:** [Legatum infantry source](https://pub-fb5c281dd12d4ea4bbd38d657cdeb907.r2.dev/app/src/assets/units/infantry-source.png), project CC BY 4.0. Downloaded to `assets/infantry/painting-source.png`; registered to `app/src/assets/units/infantry-256.png` before frozen camera UV projection. Existing prompt: `app/src/assets/units/infantry.art-pass-3.prompt.txt`.
- **Anatomy:** [MPFB 2.0.18](https://github.com/makehumancommunity/mpfb2/releases/tag/v2.0.18), GPL software; CC0 generated anatomy, morphs, 53-bone game_engine skeleton and weights. [MakeHuman system assets](https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip), CC0 eyes. Existing isolated installation reused.
- **Open motion:** [Quaternius Universal Animation Library Standard](https://quaternius.com/packs/universalanimationlibrary.html), Standard 2025-06-10, CC0 1.0. `Idle_Loop`, `Walk_Loop`, `Hit_Chest`, `Death01`. [Immutable glTF mirror](https://raw.githubusercontent.com/J-Ponzo/gltf-universal-animation-library/e24c23cf2a1323488a3faa226ea7ea21f644b73e/glTF/AnimationLibrary_Godot_Standard.gltf) and adjacent `.bin`. Included licence retained at `assets/quaternius-ual/LICENSE`. Source reference/rest matrices and complete bone rolls are compensated by Blender world-space rotation constraints; carrying arms retain the open idle layer. No post-retarget foot rotation correction.
- **Unseen surfaces:** existing original mounted-family imagegen linen/coat texture quadrants, 2026-11-22, project CC BY 4.0; no public URL. `assets/horseman/fill-linen.png` and `fill-coat.png`, recoloured olive/canvas/leather. Original prompt retained in `reused-fills.prompt.txt`. No new image generation or paid service.
- **Code reuse:** MPFB helpers from the spearman lead; rest/reference retarget, render/review/pack scaffold copied from the trench-infantry lane into this unit's isolated directory. Family playbook inspected with `git show astra/unit-anim-3d-v2:tools/art/anim3d/PLAYBOOK.md`. Original MIT orchestration, infantry kit and grenade attack; rendered output CC BY 4.0.
- Blender 5.3.0 GPL, Pillow 13.0.0 MIT-CMU, installed FFmpeg. No Mixamo, accounts, paid models or uploads.
